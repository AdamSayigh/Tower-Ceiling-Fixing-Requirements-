Viewing it

The guide is a single self-contained HTML file. The 3D engine, fonts and logos are all built in, so it needs no internet connection, server or install.

On a computer: download the file and open it in Chrome, Edge, Safari or Firefox.
On a phone: open it from a link on the website. It works in portrait, and the steps sit in a sheet under the 3D view.
On the website: upload it as its own page (for example towerdoors.com.au/builders/ceiling-guide). Don't paste it into a page builder that might strip the script.

It has a light and dark switch in the header. The choice is remembered on that device.

Updating it

This HTML file is the finished, packed build — the code is minified and the fonts and images are embedded, so it is not meant to be edited by hand.

To change words, steps or the 3D model, edit the source project and rebuild:

guide/src/chapters.js — all step text, sub-steps, labels and dimensions
guide/src/template.html — page layout, header, hero text, contact details
guide/src/model.js — the 3D garage, door, tracks and pads
then run node build.mjs in the guide folder to produce a new HTML file

When the requirements change, update the PDF documents first, then the guide and film to match, and bump the revision letter in all three.
